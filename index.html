Approach

  1. 01

    Measure first. Build the evaluation set before the clever part, so an improvement can be told from a regression.

  2. 02

    Report the misses. Confidence intervals, refusals and failure cases go in the README next to the headline number.

  3. 03

    Implement, then compare. Write the core idea from scratch to understand it, then benchmark it against the library.

  4. 04

    Make it run end to end. A model nobody can call, replay or test is a notebook, not a system.
